# Yocto layer for CatPlay (Carplay2Air)
  
Yocto version: scarthgap  
Depdendencies:  
- meta-clang@scarthgap
- meta-freescale@scarthgap
- meta-openembedded@scarthgap
- openembedded-core@scarthgap
- bitbake@yocto-5.0.10

## Flashing tools

Run the flasher scripts with `pipx run wizard.py` (or `uv run wizard.py`). Dependencies are installed automatically. See `docs/` for device guides.
