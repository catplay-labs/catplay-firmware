### Introduction

V821 represents a wide family of devices produced by one of the manufacturers, pairing Allwinner V821B chip with either RTL8733BS or AIC8800D80 radios.

It runs `cpbox-abroad` branch of firmware which has a pretty awful reputation.  
The company behind the firmware refers to themselves as `Liaoyuan` for whatever reasons.  
Wooboobox which is known for their own independent firmware, which the users liked because of better performance(better than `cpbox-abroad`, worse than CatPlay _obviously_), skipped porting to V821 and licensed `cpbox-abroad` instead.  

This never happened in recent history and we've never seen a Wooboobox running such firmware; we speculate that the V821 SDK was too complex to invest in a port from scratch for them.

Since the newer Carlinkits are just clones of Wooboobox, the exact same firmware followed them.

> [!NOTE]
> There is no V821B+AIC8800D80 build available because of no access to reference device to confirm power sequence and SDIO sample tuning.
>
> If you would like a test build, please make your interest and device model known.

Known devices include:
- Wooboobox B12 / RTL8733BS ("orange Wooboobox with a FEL button")
- Carlinkit Mini Ultra 1 / RTL8733BS (exact clone of Wooboobox B12 in a smaller form factor)
- EKIY EC03 / RTL8733BS
- CPC200-CCPA / AIC8800D80 (another marketing stunt by Carlinkit, it doesn't do anything which devices of smaller form factor don't do, runs the exact same cpbox-abroad firmware and the PCB is just artifically spread to fit the big casing)
- Carlinkit Mini Ultra 3-5 / AIC8800D80 (exact details to be confirmed but there is a photo of Ultra 3 insides showing V821 paired with AIC8800D80)

### Controversies

A few months back, Carlinkit started swapping the PCB from Ingenic X1600/AIC8800D80 to V821/RTL8733BS _without changing the product model/id_.  
Internet was outraged because the awful `cpbox-abroad` firmware paired with a _downgrade_ of the radio chip, resulted in a terrible latency and poor network performance

Thankfully, the CatPlay V821/RTL8733BS port from the first release offers unbeatable performance and stability, almost on-par with original CatPlay X1600/AIC8800D80 experience.  

RTL8733BS is just a bit worse at filtering interference on the road and may drop a few packets of audio from time to time, but otherwise CatPlay's integration with this radio is extremely stable(no issues regarding performance/memleak/panics etc.)  

There are also plans to cut CPU usage even futher for V821 platform after first release, but the CPU is already keeping up pretty well.

## Flashing wizard

> [!NOTE]
> All steps require the device to be connected to PC's USB port

### Install dependencies

```console
$ python3 -m pip install pyusb paramiko cryptography pylibfdt
$ sudo apt install -y libusb-1.0-0 squashfs-tools swig python3-dev build-essential
```

### Ensure the right directory
The scripts expects to run from the `tools` directory of unpacked firmware build, so:
```console
$ cd tools/
``` 

#### Flash firmware on device already running CatPlay V821 firmware ("refresh")

```console
$ python wizard.py --refresh
```

#### Flash firmware on device that is already in FEL when booted using FEL button

> [!NOTE]
> Ensure you plug the device into USB port while holding the FEL button. You can release it shortly after.

```console
$ python wizard.py --already-fel
```
#### Flash firmware over original cpbox-abroad firmware

> [!NOTE]
> Start with active internet connection. Switch your Wi-Fi to device's hotspot when asked by the wizard. 
> Password `12345678` or `88888888`    

> [!NOTE]
> Presets:
> - `carlinkit` — Carlinkit Mini Ultra
> - `wooboobox` — orange Wooboobox with a FEL button (for testing purposes, since already you have the button)
> - `ekiy` — EKIY EC03

> [!WARNING]
> This is a strictly Unix-native process, requiring `squashfs-tools` on the host machine

```bash 
$ python wizard.py --preset carlinkit|wooboobox|ekiy
```

### After flashing

The device reboots into CatPlay. Its Wi-Fi networks are `C2A_AP` and `C2A_P2P`; the password is `lovec@ts`. SSH is available at `root@192.168.50.2` over the device Wi-Fi. You will need to pair your phone again.

## Capturing logs

If CatPlay does not work with your car, reproduce the issue and collect `/var/log/catplay.log` and `dmesg` from the device. You can save the latter on the device with:

```console
$ dmesg > /var/log/kernel.log
```

Include both logs and the car model when reporting the problem.
